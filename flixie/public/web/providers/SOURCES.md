# Provider button assets

Google's four-colour G comes from the official Android + Web / Light / no-text
square SVG in https://developers.google.com/static/identity/images/signin-assets.zip.
Only its outer square background/border paths are omitted, since the semantic
button supplies that surface. G artwork, aspect ratio and clear space are retained.
Google Sans Medium is self-hosted from Google's Fonts CSS endpoint for that family.
Usage: https://developers.google.com/identity/branding-guidelines.

Apple's white logo-only PNG is generated by Apple's official button service:
https://appleid.cdn-apple.com/appleid/button/logo?size=44&scale=3&color=white&border=false&border_radius=0
It is unmodified and displayed with the supplied clear space at 44 CSS px.
Usage: https://developer.apple.com/documentation/signinwithapple/incorporating-sign-in-with-apple-into-other-platforms

Both marks are used solely for their respective sign-in actions. Labels remain
real, scalable text inside native HTML buttons; these are branded owned controls,
not Google Identity Services or Apple SDK-rendered buttons.
